# RoofStudio v1.0 — проработанные чертежи и условные обозначения ВШ

Добавлено в версии 1.0:

- более проработанный план чердака: наружный и внутренний контур, штриховка стен, размерные линии, линия разреза 1-1;
- разрез, визуально ближе к рабочему чертежу: двойные линии кровли, стены, условные элементы стропильной схемы и размеры;
- ВШ на плане отображаются как условные обозначения в духе ГОСТ: контур, диагонали, осевые линии и выноска с маркой;
- люки и опорные столбы также показываются отдельными условными обозначениями;
- DXF-экспорт чердака и разреза обновлён под новый вид.

Важно: модель остаётся предварительной и предназначена для ускорения проектирования и подготовки чертежей на основе обмеров.

## Сборка EXE через GitHub Actions

1. Загрузите содержимое папки `RoofStudio_v1.0` (или переименуйте её по желанию) в корень репозитория.
2. Убедитесь, что файл `.github/workflows/build-windows.yml` присутствует в репозитории.
3. Откройте вкладку **Actions** и запустите сценарий **Build RoofStudio Windows EXE**.
4. Скачайте артефакт `RoofStudio_v1.0_Windows_x64`.
